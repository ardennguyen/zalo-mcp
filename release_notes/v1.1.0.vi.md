## zalo-mcp 1.1.0

> Release notes đề xuất. Cần nhánh upstream `v1.1.0`, engine đã phát hành có
> PR #2/#3/#4, lockfile tạo lại và kiểm tra cài đặt/CI đạt. PR wrapper còn draft.
> Chưa tạo tag hay release.

Chọn tài khoản ngay trong MCP client, nhận engine 2.x tương thích qua
`@ardennguyen/zalo-agent-cli` **^2.0.1**, thay cho cố định 2.0.0.

### Điểm nổi bật

- **Chuyển `--account <ID>` hoặc `--account=<ID>`.** Dùng toàn bộ ID chuỗi số
  trong danh sách tài khoản engine. Không ép kiểu số JavaScript. Giá trị sai,
  thiếu hoặc lặp bị từ chối trước cài đặt/đăng nhập.
- **Engine quyết định hành vi tài khoản.** Engine chọn credentials, giữ khóa
  tài khoản và ghim reconnect. Bỏ flag giữ mặc định engine. Engine cũ từ chối
  flag thì dừng; wrapper không thử lại bằng tài khoản active.
- **Nhận engine tương thích.** `^2.0.1` nhận các bản 2.x dưới 3.0.0. Lockfile
  vẫn chọn một phiên bản chính xác; đổi dải không tự nâng bản đang cài.

### Tính năng engine mới

Khi engine đã cài chứa PR #2/#3/#4:

- Tên sender hiện tại ưu tiên alias riêng → tên profile Zalo → UID; giữ tên
  lịch sử trên tin. Sync làm mới cả tên hội thoại 1-1 đã cache.
- Ghim tài khoản qua reconnect và retry.
- **14 tool MCP**: `zalo_sync` yêu cầu sync tin nhắn/phản ứng;
  `zalo_sync_status` đọc tiến độ/kết quả. Restore tin vẫn cần bấm điện thoại.
  Job dùng socket và khóa stage sẵn có của daemon.

Đề xuất engine: [#2](https://github.com/ardennguyen/zalo-agent-cli/pull/2),
[#3](https://github.com/ardennguyen/zalo-agent-cli/pull/3),

### Cập nhật

Sau khi phát hành:

```bash
bash zalo-mcp.sh update     # Linux / macOS
.\zalo-mcp.ps1 update       # Windows
```

Thêm `"--account", "101"` sau đường dẫn launcher trong args của MCP client,
rồi restart client. `101` là ví dụ giả, thay bằng ID tài khoản đã đăng ký.
Process riêng dùng ID riêng. Không chạy npm install thủ công trong deploy đang dùng.

### Các điểm cần biết

- Cần Node.js 22 trở lên (engine thực tế cần 22.19+).
- Các tùy chọn được chuyển tiếp: `--http`, `--auth`, `--account`. Flag khác,
  gồm `--host`, `--config`, vẫn cần gọi engine trực tiếp.
- Ngày 2026-10-15 npm mới có engine 2.0.0; ^2.0.1 hiện báo ETARGET. Phát hành
  engine trước, tạo lockfile wrapper thật, kiểm tra cài đúng engine có tính
  năng rồi mới phát hành wrapper.
- Test launcher là offline. Chưa xác minh reconnect tài khoản và restore điện
  thoại thật trong công việc này. Deploy local hiện có giữ nguyên.

  và `NOTICE` về điều khoản và giấy phép thương mại.
